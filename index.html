Documentation automation & tooling

AI agents for Forge documentation

Built three AI agents using Cursor AI to accelerate documentation workflows for Atlassian's Forge platform: a changelog reviewer, a documentation PR reviewer, and a documentation feedback reviewer. Configured MCP server settings to connect the agents to Atlassian Rovo MCP (internal Confluence specs and requirements), Forge Knowledge MCP (platform technical details), and Atlassian's developer documentation style guide. Turned a two-week manual process involving engineers, PMs, and stakeholders into an automated system that lives in the docs repository and reviews against content standards on its own.

About

Building bridges between complexity and clarity

I'm a senior technical writer and senior content designer with over 17 years of experience creating documentation, content systems, and user experiences for technology companies.

My work sits at the intersection of technology and communication. I translate complex concepts into clear, actionable content that helps people succeed. From developer documentation to end-user guides, and from admin interfaces to customer-facing content, I craft experiences that respect both the technology and the people using it.

Most recently at Atlassian, I specialised in developer audiences, but my expertise spans all user types. I believe great documentation is more than accurate information. It's a thoughtfully designed experience that anticipates user needs, removes friction, and builds confidence.

When I'm not writing documentation, I'm usually writing songs, enjoying the beach, or discovering new restaurants alongside my partner (the actual foodie). Music, movies, sports, and crime shows round out my interests, best enjoyed with family and friends.
